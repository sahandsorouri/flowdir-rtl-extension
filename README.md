# FlowDir

A browser extension that sets the right text direction for Persian and Arabic text on any site, without changing fonts.

## What it does

- Switches inputs and text areas to right-to-left when you type Persian or Arabic.
- Switches back to left-to-right for Latin text.
- Works on all sites.
- Does not touch your fonts.

## Install

1. Download this folder.
2. Open `chrome://extensions` or `brave://extensions` and turn on Developer mode.
3. Click "Load unpacked" and pick the folder.

## Tech

Manifest V3 content script (`content.js` and `content.css`), plain JavaScript.
