# FlowDir

> A browser extension that automatically fixes RTL and LTR direction for inputs with Farsi or Arabic text, without changing fonts.

## What it does

When you type Farsi or Arabic into any input or textarea, FlowDir sets the text direction to right-to-left automatically, and back to left-to-right for Latin text. It works on all sites and does not touch your fonts.

## Install (developer mode)

1. Download this folder.
2. Open `chrome://extensions` or `brave://extensions` and turn on Developer mode.
3. Click "Load unpacked" and select the folder.

## Stack

Manifest V3 content script (`content.js` + `content.css`).
